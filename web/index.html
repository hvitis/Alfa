class PlayerSession:
  """Offline audio & letters"""
  def __init__(self, img, snd, audio):
    self.gallery = Gallery(img)
    self.audio = audio
    self.guard = MashGuard()

  def accept_press(self, key, now):
    if not self.guard.accept(now):
      return False
    return self.handle(key)

MAŁA CHMURKA, ZBUDOWANA, BY TRZYMAĆ.

Radio-chmurka.

PETG / V2 ARCADE
01 / DRUK 3D

Dwie skorupy. Jedna mała chmurka.

Chmurka 206 × 211 × 72 mm ma osobną boczną pokrywę baterii. Bateria i Raspberry Pi leżą równolegle do tylnej pokrywy. Pięć przycisków pozostaje w przedniej skorupie po otwarciu obudowy, a głośnik gra przez siedem otworów w kształcie chmur.

Widok złożenia

Pasowanie prototypu: niepewne wymiary mają 5 mm naddatku łącznie, 2,5 mm na stronę. Wydrukuj kupony zatrzasków i sprawdź swój sprzęt przed złożeniem.
