# Letter recording placeholders

Each filename below is an optional recording slot.
The drawing lesson runs silently until its file exists.
Use stereo, 48 kHz, 16-bit PCM WAV recordings.
The player plays each recording in full and keeps the completed letter visible until playback ends.
